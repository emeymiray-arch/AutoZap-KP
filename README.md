# КП AutoZap для поставщиков

Отдельное коммерческое предложение на бланке AutoZap для каждой компании. Условия одинаковые, меняется адресат.

Файлы лежат в папке [`kp/`](kp/):

| Компания | Файл |
| --- | --- |
| ООО «Бренд-Партс» | `KP-AutoZap-OOO-Brend-Parts.pdf` |
| ООО «СК-ОПТ-ШИНА» | `KP-AutoZap-OOO-SK-OPT-SHINA.pdf` |
| ООО «СПЕЦСТАЛЬЗАПЧАСТЬ» | `KP-AutoZap-OOO-Specstalzapchast.pdf` |
| ООО «АВТОЛАДА» | `KP-AutoZap-OOO-AvtoLada.pdf` |
| ООО «ТПК „Трансснаб“» | `KP-AutoZap-OOO-TPK-Transsnab.pdf` |
| ООО «АВТОХАДОМ» | `KP-AutoZap-OOO-AvtoHadom.pdf` |
| ООО ТД «ЖИВАЯ СТАЛЬ» | `KP-AutoZap-OOO-TD-Zhivaya-Stal.pdf` |
| ООО «ТРАНСКАВКАЗ» | `KP-AutoZap-OOO-Transkavkaz.pdf` |

Шапка: логотип AutoZap, название компании и телефон +7 (927) 877-77-95.

Пересобрать все PDF (нужен Google Chrome):

```bash
./scripts/make-pdf.sh
```
