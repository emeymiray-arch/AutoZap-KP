# КП AutoZap в интернете

Статический сайт без базы данных и без GitHub: список коммерческих предложений, просмотр листов и скачивание PDF/Word.

Телефон берётся из файла `.env` / `.env.example`:

```
VITE_PHONE=+7 (927) 877-77-95
```

## Локально

```bash
npm install
npm run dev
```

Откроется http://127.0.0.1:43147

## Vercel

Сборка: `npm run build`. Папка `dist` — готовый сайт. GitHub подключать не нужно.
