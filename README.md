# КП AutoZap × ARMTEK

Печатное коммерческое предложение о сотрудничестве площадки **AutoZap** и компании **ARMTEK**. Документ сверстан на 4 листа A4: его можно открыть в браузере, распечатать или скачать PDF.

## Как открыть

```bash
npm install
npm run assets
npm run dev
```

Приложение откроется на [http://127.0.0.1:43147](http://127.0.0.1:43147).

- **Скачать PDF** — готовый файл `public/KP-AutoZap-ARMTEK.pdf`
- **Печать** — диалог браузера, формат A4 без полей

## Собрать PDF заново

Нужен запущенный dev-сервер и Google Chrome:

```bash
npm run pdf
```

## Состав документа

1. Обложка
2. Суть предложения и пункты 1–3
3. Продвижение, регионы, СТО и модель взаимодействия
4. Приложение AutoZap, цель сотрудничества и блок подписей
